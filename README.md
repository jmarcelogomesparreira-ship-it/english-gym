# English Gym

Treino diário de inglês: frases do dia a dia, palavras, 104 verbos nos 3 tempos, flashcards com revisão espaçada, 68 erros comuns de brasileiro, ditado, pronúncia, textos e regras. Mostra sequência de dias, tempo estudado e meta diária.

## Publicar no GitHub Pages

1. Crie um repositório público chamado `english-gym`.
2. Envie todos os arquivos desta pasta (Add file → Upload files).
3. Settings → Pages → Branch: `main`, pasta `/ (root)` → Save.
4. Em 1 ou 2 minutos o app fica em `https://SEU-USUARIO.github.io/english-gym/`.

## Instalar no celular

Abra o link no Chrome (Android) → menu ⋮ → **Adicionar à tela inicial**. No iPhone: Safari → Compartilhar → **Adicionar à Tela de Início**. Depois disso funciona até sem internet.

## Progresso

Cada pessoa tem o seu progresso salvo no próprio celular. Use **Hoje → Salvar backup** antes de trocar de aparelho.

## Atualizar

Ao mudar o `index.html`, troque a versão em `sw.js` (ex.: `english-gym-v3`) pra os celulares pegarem a versão nova.
